In this chapter you will... 

- Get an understanding of what the AUTOSAR methodology is and which problems it solves.
- Learn about the exchange of information, development process, types of .arxml files and the challenges of new use cases.

The AUTOSAR Methodology defines a sequence of steps and activities for the development of AUTOSAR systems. The Methodology leads from a description of soft- and hardware to the generation of an executable file per ECU. 

The main goals of the AUTOSAR Methodology is to build the software functionality independent from the rest of the system and to provide a basis for a standardized cooperation between an OEM and the TIER1 suppliers. This is achieved through the use of uniform templates.
