Now we will have a look inside of those Software Components. What we need here is code and to execute that code. This is normally done with the help of Runnables. 

# **What Are Runnables?**

- Runnables are C-Functions containing the actual implementation.
    - E.g. _void Runnable(void)_
- Runnables might be executed when RTE Events (triggers) occur.
    - E.g. when data is received, a timer expires or by a function call

Atomic Software components contain one or more runnable entities (Runnables) as part of their internal behavior. A runnable entity is the executable unit of a software component.
