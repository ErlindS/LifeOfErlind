## What is MICROSAR?
MICROSAR is the embedded software for your AUTOSAR ECUs. It consists of the runtime environment MICROSAR RTE and MICROSAR basic software modules (BSW). They cover the entire AUTOSAR standard and contain a lot of useful extensions. The uniform and intuitive user interface of DaVinci Configurator Classic is used to configure the MICROSAR modules.
