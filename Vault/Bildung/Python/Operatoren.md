Zumal gibt es Konvertierungsoperatoren wie
```
int() 
str()
float()
bool()
list()
```
Strings und Listen können zusammenaddiert werden

```
l = [1,2,3]+[4,5,6]
s = "abc" + "def"
```

Allgemeine Operatoren zum Rechnen

```
• Betrag bilden: abs(a) 
• Maximum zweier Zahlen: max(a,b) 
• Minimum zweier Zahlen: min(a,b) 
• Zahlen runden: round(a) 
• Benutzereingabe: input("Eingabe bitte:") 
• Liste sortieren: sorted(l) 
• Summe von Zahlen einer Liste: sum(l)
```

Es gibt einen "in" Operator welche überprüft, ob sich ein Element in einer Liste oder einem String befindet
```
42 in [1,13,42,99]
-> True
```
